🛒 微商城API系统

测试工程师项目演示 · FastAPI + SQLAlchemy + JWT · 2026

核心业务链路

用户认证（注册/登录）→ 商品查询（列表/详情/搜索）→ 订单创建（购物车/下单）→ 支付回调（支付/状态更新）

技术栈

Python FastAPI SQLAlchemy SQLite/MySQL JWT认证 pytest Requests JMeter JSON Schema Docker

接口清单

POST/api/register 注册
POST/api/login 登录
GET/api/me 个人信息
GET/api/products 商品列表
GET/api/products/{id} 详情
POST/api/orders 创建订单
GET/api/orders 订单列表
POST/api/payment/callback 支付回调
